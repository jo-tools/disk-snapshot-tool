# Third-Party Licenses

The full license texts for everything Disk Snapshot Tool bundles. Each file is
the component's own text, copied verbatim from the source the build compiles.

[THIRD-PARTY-NOTICES.md](../THIRD-PARTY-NOTICES.md) explains what each component
is, why it is here, and what redistributing a build obliges you to do. This
folder is only the texts themselves.

| Component | License | Text |

| GLib | LGPL-2.1-or-later | [GLib-LGPL-2.1.txt](GLib-LGPL-2.1.txt) |
| proxy-libintl | LGPL-2.0-or-later | [proxy-libintl-LGPL-2.0.txt](proxy-libintl-LGPL-2.0.txt) |
| QEMU | GPL-2.0-only | [QEMU-GPL-2.0.txt](QEMU-GPL-2.0.txt) |
| QEMU | licensing overview | [QEMU-LICENSE.txt](QEMU-LICENSE.txt) |
| Zstandard | BSD-3-Clause *(dual GPL-2.0)* | [Zstandard-LICENSE.txt](Zstandard-LICENSE.txt) |

These files are copied into the application bundle at `Contents/Resources/`, and
the app's Help menu shows them.
